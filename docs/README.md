# Data Mining — Living Study Guide

This directory is a version-controlled learning journal and case study for **Predicting Online Shopping Purchase Intention Using Machine Learning and Feature Selection**.

## How to use it
Read lessons in numerical order. Each lesson distinguishes explanations and hypothetical teaching examples from outputs actually observed in the research environment. Re-run commands in GitHub Codespaces to reproduce practical steps.
